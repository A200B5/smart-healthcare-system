1. Request arrives
   ↓
2. Route handler extracts body/params
   ↓
3. Validator checks input (returns errors array if invalid)
   ↓
4. If invalid: return 400 with error response
   ↓
5. If valid: use validated (sanitized) data
   ↓
6. Database operation with clean data
   ↓
7. Return success response
